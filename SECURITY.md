# Security

## Report a security problem

Send it to `security@sl0ptiminer.com`. The same address is in [security.txt](https://sl0ptiminer.com/.well-known/security.txt).

When you report: say which version, which system and what you saw. Do not post wallet keys or passwords anywhere.
