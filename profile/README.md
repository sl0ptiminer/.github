# Sl0ptiminer

> Optimized for your mining pleasure.

Sl0ptiminer is a cryptocurrency miner. It mines Hoohash for Hoosat (HTN), on x86-64 processors, 64-bit ARM processors and NVIDIA graphics cards. Systems: Linux, macOS and HiveOS. **No public build yet.**

The official site is https://sl0ptiminer.com: downloads, install guides, a wiki and measured benchmarks. From the first release, the same signed packages are in the [release repository](https://github.com/sl0ptiminer/sl0ptiminer), the second official source.

- [Start mining with Sl0ptiminer](https://sl0ptiminer.com/wiki/quick-start/)
- [Download Sl0ptiminer](https://sl0ptiminer.com/download/)
- [Install guides for mining systems](https://sl0ptiminer.com/guides/)
- [Algorithms and coins](https://sl0ptiminer.com/algorithms/)
- [Sl0ptiminer benchmarks](https://sl0ptiminer.com/benchmarks/)
- [Security and verification](https://sl0ptiminer.com/wiki/verify/)

Sl0ptiminer is closed source and paid for by a [developer fee](https://sl0ptiminer.com/wiki/fee/).
