Sl0ptiminer is a cryptocurrency miner. It mines Hoohash for Hoosat (HTN), on x86-64 processors, 64-bit ARM processors and NVIDIA graphics cards. Systems: Linux, macOS and HiveOS. **Current version 0.8.5**, released 2026-11-23. [What changed](https://sl0ptiminer.com/releases/#v0-8-5)

The official site is https://sl0ptiminer.com: downloads, install guides, a wiki and measured benchmarks. The same signed packages are in the [release repository](https://github.com/sl0ptiminer/sl0ptiminer), the second official source.
